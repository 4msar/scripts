Available scripts

Shell utilities hosted at https://scripts.msar.me/. Run from a terminal; hosts scripts need administrator rights.

  1. setup-husky.sh

    Installs and configures Husky with pre-commit and commit-msg hooks for Laravel/Vue-style projects (checks project directory, package manager, etc.).

    Use

    curl -sSL https://scripts.msar.me/setup-husky.sh | bash
    curl -sSL https://scripts.msar.me/setup-husky.sh | bash -s -- /path/to/project

  2. add-hosts-domain.sh

    Adds one or more local domains to /etc/hosts as 127.0.0.1 entries. Optional --verify (-V) to verify the file; --help (-h) for usage.

    Use

    curl -sSL https://scripts.msar.me/add-hosts-domain.sh | sudo bash -s -- domain1.test domain2.test
    sudo bash add-hosts-domain.sh --verify domain1.test

  3. remove-hosts-domain.sh

    Removes matching domain lines from /etc/hosts. Same flags as add: --verify, --help.

    Use

    curl -sSL https://scripts.msar.me/remove-hosts-domain.sh | sudo bash -s -- domain1.test
    sudo bash remove-hosts-domain.sh domain1.test domain2.test

  4. set-editor.sh

    macOS: uses duti to set the default app for many code-related file extensions. Edit EDITOR_ID inside the script (e.g. bundle id for VS Code or Zed) before running.

    Use

    curl -sSL https://scripts.msar.me/set-editor.sh | bash
